# TECHFEST — Beyond The Possible

A responsive, futuristic 3D event website concept featuring a Three.js animated hero scene, pointer-reactive 3D core, GSAP scroll reveals, event cards, and responsive layouts.

## Run locally

No build step is required. Open `index.html` in a modern browser. For the best experience, use VS Code with the **Live Server** extension and click **Go Live**.

## Files

- `index.html` — page structure and CDN imports
- `style.css` — visual design, responsive layout, transitions
- `script.js` — Three.js scene, pointer interaction, GSAP scroll animations

## Customize before submission

This is a fictional Techfest concept. Replace the event title/date, registration email, and event details with the real organizer information before publishing. The registration link is currently a placeholder email address.

## Publish on GitHub Pages

1. Create a new public GitHub repository, for example `techfest-3d-experience`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish. Submit the published Pages URL, or submit the repository URL if the form accepts a GitHub project link.

External libraries and fonts are loaded from CDNs, so an internet connection is needed for the full 3D experience.
